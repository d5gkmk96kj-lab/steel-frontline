# ==========================================================================
#  钢铁战线 · 游戏提示（Tips）
# ==========================================================================
#
#  这个文件里的每一行 = 一条提示，游戏会随机挑一条显示。
#
#  【怎么写】
#    · 一行一条，想加多少加多少
#    · 空行会被忽略
#    · 以 # 开头的行是注释，不会显示
#    · 不用加引号、不用加编号
#
#  【显示位置】
#    主菜单底部 / 加载时 / 战役胜利页 / 战役失败页
#
#  【想分场景？】
#    用下面的标记分节，某个场景只显示它那一节的内容：
#
#      [菜单]      只在主菜单显示
#      [加载]      只在加载时显示
#      [胜利]      只在通关时显示
#      [失败]      只在战败时显示
#
#    没有归入任何分节的提示 = 通用提示，上面所有场景都可能显示。
#
#  【什么时候生效】
#    游戏启动时读取。改完重启游戏即可，不用重新打包。
#    如果这个文件是空的（或者全被注释掉），游戏会显示内置的几条兜底提示。
#
